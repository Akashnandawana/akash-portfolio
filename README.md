# Akash Nandawana — Portfolio

Source code exported from the existing portfolio on 5 October 2026.

This is a static website. HTML, CSS, JavaScript, images and downloadable PDFs are included. No npm installation or build step is required.

## Upload to GitHub

1. Create a GitHub repository named `akash-portfolio`.
2. Extract this ZIP on your computer.
3. Upload the extracted files and the `assets` folder to the repository root. `index.html` must be at the root, not inside another folder. Do not upload the ZIP itself.
4. Commit the files.

## Run locally

From this directory, run `python -m http.server 8000`, then open http://localhost:8000.

## Hosting

The repository contains source code; uploading it does not automatically host the site. For GitHub Pages, use the repository's Settings → Pages and publish the main branch from the root folder.

After GitHub Pages is active, you can configure your custom domain in its Pages settings and update DNS at your domain provider. DNS instructions for ChatGPT Sites do not apply to GitHub Pages.

## Files

- `index.html`: page structure and content.
- `*.css`: styles.
- `*.js`: interactive behaviour.
- `assets/`: images, CV and evidence portfolio PDFs.

Review the included PDFs and portfolio content before making the repository public.
